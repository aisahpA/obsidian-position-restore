# 术语对照表（中文说法 ↔ 代码里的名字）

**用法**：写注释、写导读、给你汇报时，一律以本表的中文列为准；指在代码符号时用「代码名列」放进反引号。
**表是活的**：看到一个没登记的概念就补一行，补完再在别处用这个词。

> 原则：**代码符号不翻译**。这里的中文是用来*说*它的，不是用来*改*它的。

---

## 概念词

| 中文 | 代码里的名字 | 是什么 / 易混点 |
|---|---|---|
| 一行 | `navGroupKey` | 列表里归并出来的一行。`view` 是 `view:类型`，其余是文件路径 |
| 一个地点 | `placeKey` | 最近文件列表里的一条记录。**一行 ≠ 一个地点**：同一文件的多个标题是多个地点 |
| 步 | `NavEntry`（栈里的一个元素） | 前进后退栈里的一步。`t` 是采集戳 |
| 标题 / 落点 | `landing` / `jump` | 用户可见说法已经改成「**标题**」，但代码和 i18n key 还叫 `landing`。旧说法「落点」已废弃 |
| 命名的跳转 | `kind: 'jump'` | 点了大纲标题、点了锚点链接、块引用跳转。带 `key` |
| 访问 | `kind: 'visit'` | 打开文件、切标签页/分屏。没有 `key`，不自带位置 |
| 视图地点 | `kind: 'view'` | 没有文件的主区视图：关系图谱、搜索、备忘 |
| 跳变 | `kind: 'teleport'` | **推断**出来的同文件大跳跃：vim 跳转、跳到某行。默认阈值 0（不启用） |
| 标题所在行 | `keyLine` / `landedLine` | `key` 指向的那个标题，在记录当时在第几行 |
| 离开位置 | `leftAt` | 离开这一步时读者站的位置。**只有前进后退能兑现它** |
| 落地 | landing settle | 打开笔记后真正滚到位的那一刻，`keyLine` 在这时校准 |
| 引文 | `context` | 落点行附近的原文摘录。**只为标题存在** |

## 坐标

| 中文 | 代码里的名字 | 是什么 / 易混点 |
|---|---|---|
| 顶行 | `st.scroll` | 视口最上面那一行，**0 起算的行号，不是像素** |
| 光标 | `cursor` / `st.c` | 同样是行号单位 |
| 当时 vs 现在 | `nowLineFor()` | 列表上显示的是「当时」的行号；**要打开笔记前必须先换算成「现在」** |
| 锚点 | anchor | 靠一小段原文 + 邻近行，在文本变动后重新定位原来的行 |
| 重锚 | re-anchor | 文本改动后，把位置挪到新文本中的对应位置 |

## 时机与阈值

| 中文 | 代码里的名字 | 是什么 / 易混点 |
|---|---|---|
| 打开保护窗口 | `OpenCover` | 刚打开笔记、位置还没稳的那段时间，不记录用户位移 |
| 落地吸收窗口 | `LANDING_ABSORB_MS`（3000） | 这段时间内到达的推断跳变当成哑的一步 |
| 漂移成步下限 | `DEPARTURE_MIN_LINES`（10） | 离开命名标题走了多少行才算「真的走了」 |
| 采样间隔 | 100ms / `VIEW_STATE_POLL_MS`（1000） | 位置采样 vs 视图 state 轮询，两个不同频率的 tick |

| 中文 | 代码里的名字 | 是什么 / 易混点 |
|---|---|---|
| 重画 | `render()` | 重建列表 DOM。成本几乎全在 DOM；**不要**加 memo / 脏标记优化 |
| 搜索面 | `printed()` | 一行里能被搜到的那部分文本。行号不参与搜索 |

## 容易翻错、干脆别翻的

- **`scroll`**：就是「滚到第几行」。别翻成「滚动条位置」「滚动量」。
- **`render`**：内部统一说「重画」，不要说「渲染」（跟 Obsidian 的 reading/preview rendering 混）。
- **`step` / `visit` / `place`**：三个不同层级的东西，别都翻成「记录」。
- **`landing`**：对外说法已经是「标题」；写注释时也写「标题」，只在提到代码符号时用 `landing`。
