# 术语对照表（中文说法 ↔ 代码里的名字）

**用法**：写注释、写导读、给你汇报时，一律以本表的中文列为准；指在代码符号时用「代码名列」放进反引号。
**表是活的**：看到一个没登记的概念就补一行，补完再在别处用这个词。

> 原则：**代码符号不翻译**。这里的中文是用来*说*它的，不是用来*改*它的。

---

## 概念词

| 中文 | 代码里的名字 | 是什么 / 易混点 |
|---|---|---|
| 一行 | `navGroupKey` | 列表里归并出来的一行。`view` 是 `view:类型`，其余是文件路径 |
| 一个地点 | `placeKey` | 最近文件列表里的一条记录。**一行 ≠ 一个地点**：同一文件的多个标题是多个地点 |
| 步 | `NavEntry`（栈里的一个元素） | 前进后退栈里的一步。`t` 是采集戳 |
| 落点 | `landing` / `jump` | 一次带 `key` 的跳转落地之处。**UI 文案里叫「标题」**，但两者不是一回事 —— 见下方「落点 ≠ 标题」 |
| 命名的跳转 | `kind: 'jump'` | 点大纲标题、点锚点链接、块引用跳转、搜索命中（`caller:`）。带 `key` ⇒ 是唯一能成为落点的一类 |
| 访问 | `kind: 'visit'` | 打开文件、切标签页/分屏。没有 `key`，不自带位置 |
| 视图地点 | `kind: 'view'` | 没有文件的主区视图：关系图谱、搜索、备忘 |
| 跳变 | `kind: 'teleport'` | **推断**出来的同文件大跳跃：vim 跳转、跳到某行。默认阈值 0（不启用） |
| 落点行 | `keyLine` / `landedLine` | 这一步落在第几行。`jump` 从自己的 `key` 作答；`visit` / `teleport` 走兜底 `st.scroll ?? cursor.from.line`（那时跟标题无关） |
| 离开位置 | `leftAt` | 离开这一步时读者站的位置。**只有前进后退能兑现它** |
| 落地 / 落定 | landing settle | 打开笔记后真正滚到位的**那一刻**，`keyLine` 在这时校准。指事件不指位置 —— 位置叫「落点」 |
| 引文 | `context` | 落点行附近的原文摘录。**只为落点存在**（`visit` 没有） |

### 落点 ≠ 标题

这两个词被并进同一格过一次（我记岔了），这里把界线钉死：

- **落点是概念**：`landing` 指一次跳转落地之处，`landedLine()` 对 `visit` / `teleport` 也照样回答
  「这一步落在第几行」（兜底 `st.scroll ?? cursor.from.line`，`entry.ts:187-196`）—— 那时它跟标题毫无关系。
- **标题是 UI 说法**：`en.ts` 里 `recentFiles.landings.options.*` 的原文就是 "Headings, one row per note"、
  `forgetLanding` 是 "Remove this heading"。zh.ts 译「标题」忠实原文，**i18n 一个字都不用动**。
- **最近文件列表里，剩下的落点确实全是标题 —— 那是结果，不是定义。`places.ts:294-301` 把
  `caller:`（搜索命中）与 `#^block`（块引用）都降级成那篇笔记的 `visit`：列表叫不出它们的名字。
  降级之后 places 里只剩标题跳转。
- **前进后退栈不降级**（行为定案 23）。所以**栈语境下的落点不全是标题** —— 那里 `caller` / `block`
  型的 `jump` 照样是一步 ⇒ 写栈相关文字时必须说「落点」，说「标题」会把这条定案讲反。

用法：注释 / 导读 / 汇报写「落点」；只有界面上给用户看的那句话写「标题」。

## 容易翻错、干脆别翻的

- **`scroll`**：就是「滚到第几行」。别翻成「滚动条位置」「滚动量」。
- **`render`**：内部统一说「重画」，不要说「渲染」（跟 Obsidian 的 reading/preview rendering 混）。
- **`step` / `visit` / `place`**：三个不同层级的东西，别都翻成「记录」。
- **`landing`**：概念名写「**落点**」（跳转落地之处）；「**标题**」只是对外说法，**只用于 i18n 与用户可见文案**。注释、导读、汇报一律说「落点」。
- **`heading`**：译文里的「标题」若旁边没有 `landing`，多半是这个词（笔记里 `#` 开头的那一行）。两者别混。
